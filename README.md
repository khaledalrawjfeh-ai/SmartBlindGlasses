# 👓 Smart Blind Glasses

> **Embedded AI Assistive Device for Visually Impaired Users**
>
> A wearable embedded system designed to improve environmental awareness through obstacle detection, embedded sensing, and intelligent audio feedback.

---

# Overview

Smart Blind Glasses is an embedded systems project focused on enhancing independent mobility for visually impaired users.

The project combines embedded hardware, IoT technologies, and computer vision concepts to detect surrounding obstacles and provide real-time audio guidance.

The goal is to develop a low-cost, portable, and intelligent wearable capable of improving navigation safety in everyday environments.

---

# Objectives

- Improve mobility for visually impaired users
- Detect nearby obstacles
- Provide real-time voice feedback
