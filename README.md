# 👓 Smart Blind Glasses

AI-powered assistive wearable designed to improve environmental awareness for visually impaired users.

## Objective

Develop a wearable embedded system capable of detecting obstacles and providing real-time audio feedback using low-cost embedded hardware.

## Hardware

- ESP32
- Ultrasonic Sensors
- Camera
- Speaker
- Battery

## Software

- Embedded C
- Arduino
- Computer Vision
- YOLO
- Wi-Fi
